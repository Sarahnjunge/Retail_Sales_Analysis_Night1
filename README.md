# Retail Sales Analysis

## Project Overview
A beginner data analytics project using Python and pandas to explore retail sales data.

## Objectives
- Calculate revenue and gross profit.
- Compare product performance.
- Analyse daily revenue.
- Use data to develop evidence-based business recommendations.

## Tools
- Python
- Pandas
- Google Colab

## Key Findings
- Eggs generated the highest total revenue: KSh 5,850.
- Eggs generated the highest total gross profit: KSh 910.
- October 22 had the highest daily revenue: KSh 4,420.

## Note
This project uses a small simulated dataset for learning purposes. The findings are illustrative and do not represent actual shop sales.
